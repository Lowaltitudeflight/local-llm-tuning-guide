# Code of Conduct

## Our pledge

We want participation in this project to be a harassment-free experience for
everyone, regardless of experience level, hardware budget, language, or
affiliation. The project's whole premise is that advice must state its
conditions; the same applies to how we treat each other.

## Expected behavior

- Critique the measurement, not the person. “Your TP8 number does not transfer
  because the model is different” is useful; “you don’t know what you’re doing”
  is not.
- State conditions when you disagree. A counterexample with a command and a log
  is worth more than a strong opinion.
- Respect that Chinese and English are both first-class here; do not mock
  grammar or translation.
- Do not post other people’s private data, credentials, or internal hostnames.

## Unacceptable behavior

- Harassment, insults, or discriminatory comments.
- Publishing someone’s private information without permission.
- Repeatedly derailing technical threads with vendor advocacy.
- Submitting fabricated benchmark numbers. This project’s rule is simple: an
  empty cell is better than an invented one.

## Scope

This code applies to issues, pull requests, discussions, and any project space.
It does not cover private conversations outside the project.

## Enforcement

Maintainers may edit or remove comments, close threads, or block accounts for
behavior that violates this code. Reports can be sent through the repository’s
private security advisory channel (see [SECURITY.md](SECURITY.md)) or by
contacting a maintainer on GitHub. Reports will be handled confidentially.
